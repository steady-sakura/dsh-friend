给桌边的小鲸接上声音。

第一次填入 DeepSeek API Key，点「保存并开始」就能聊天。你也可以换成兼容 Chat Completions 的接口。

聊天 API

一起看屏幕

启用后仍需选择具体窗口并同意发送。截图会交给你选的 API 服务商。选整屏还需额外确认。关闭窗口、锁屏或暂停后停止发送。

为看屏幕使用另一套 API

单位：秒。每次观察会调用一次 API；请求未完成时跳过后续采样。

它想怎么陪你

开启后会定时调用 API，由模型决定说话、做动作或安静。不需要每句话配动画。可随时关闭。

角色提示词与记忆

角色读取第一层 .md / .txt，最多 30 个文件、24,000 字符。记忆按目录读取 .md / .txt，最多 1,000 个文件、合计 32 MiB，单文件 1 MiB，支持日记子目录。私密目录、链接和疑似密钥内容始终排除。角色进入人物提示，记忆纳入本机检索。

日记、长期记忆与检索

聊天原话按天留档；模型可选择写日记、摘记有出处的原话。长期内容、近两日日记与话题检索分层使用，旧事可回查原文。没有额外的嵌入 API。

默认不发送新增记忆上下文。勾选并保存后，模型才能使用检索和回查；更换 API 地址会撤销本次勾选。未授权时仍可本机保存日记、手动搜索。原有聊天输入与角色提示仍按聊天设置发送。

卸载插件
卸载前可选择保留资料，或一并删除本机聊天、记忆、草稿、精选画面和 API 设置。导入的原始文件夹会保留。
