日记、长期记忆与检索

聊天原话按天留档；模型可选择写日记、摘记有出处的原话。长期内容、近两日日记与话题检索分层使用，旧事可回查原文。没有额外的嵌入 API。

默认不发送新增记忆上下文。勾选并保存后，模型才能使用检索和回查；更换 API 地址会撤销本次勾选。未授权时仍可本机保存日记、手动搜索。原有聊天输入与角色提示仍按聊天设置发送。



只属于这台电脑的记录
聊天按日期保存为 JSONL，不放进插件仓库。截图默认不保存。API Key 使用系统加密；无法加密时只在本次运行中保留。


回复方式
默认直接显示自然正文，动作和记忆通过独立工具传递。接口不支持工具调用时，可手动选择旧 JSON 模式；不自动更换模式或重试请求。


声音与调音
内置 Sherpa-ONNX + Kokoro，本机 CPU 即可生成。首次下载离线音色约 126 MiB；只下载公共模型，不上传聊天。启用朗读请勾选聊天面板的“本机语音朗读”。
  
用参考音频克隆音色（可选）
需要自行运行官方 CosyVoice FastAPI 服务；插件不安装 Python 或大型克隆模型。仅允许连接本机 127.0.0.1 / ::1，不上传到云端。选择 3–30 秒、16 位 PCM WAV 音频并填写逐字原文。


记忆存储位置
日记、长期记忆和摘记写在这里；和上面的只读记忆导入分开。可复制到空文件夹，或切换到已有的 DSH Friend 记忆目录。原目录保留，遇到同名内容冲突会停止。外部自选目录卸载时保留。


暂时安静
只暂停主动聊天和自动画面分析；你发消息、手动“看一眼”仍可回应。到期恢复原来的活动设置。


接口工具能力
使用已保存的聊天接口发出一次固定工具测试，会消耗少量 API 额度。不带历史、记忆或画面，也不执行动作；不会自动更改回复模式。


本机备份与恢复
备份聊天、回复留底、记忆、设置及参考音频；不包含导入目录原文、截图收藏和可重新下载的模型。备份含私人内容，请保存在自己的设备。密钥的系统加密不能跨电脑迁移。恢复前自动保留一份本机副本，不删除备份中没有的文件。
 


插件更新
检查官方 GitHub main 的版本，只允许安装已通过 CI 的确切提交。安装需要从 DSH 打开的桌宠；资料保留，更新后重新打开桌宠，不自动重启 Web。相同版本也可重新安装仓库修正。
  


卸载插件
卸载前可选择保留资料，或一并删除本机聊天、默认记忆、草稿、精选画面、回复留底、下载的音色及 API 设置。导入的原始文件夹和外部自选记忆目录会保留。
